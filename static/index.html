          How it works

          1. Ideas. Checks what's getting views on YouTube for your topic and suggests original angles.
          2. Script. Writes short spoken scenes, each paired with a footage search.
          3. Voice. Records each line with a natural-sounding voice, so captions match the speech exactly.
          4. Footage. Finds a different free stock clip from Pexels for every scene.
          5. Edit. Cuts, captions and joins everything into one MP4.
          6. Publish kit. Thumbnail, title, description and tags, checked against YouTube best practice.
